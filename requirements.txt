# =============================================================================
# 3. C/C++ development components
# =============================================================================
# Required components: readline, ncurses/tinfo, zlib, SDL2 (+ sdl2-config),
# SQLite3. Package naming differs by distribution:
#   - Ubuntu/Debian: usually *-dev (readline, zlib, SDL2, SQLite3 variants)
#   - CentOS/RHEL: usually *-devel (readline-devel, zlib-devel, SDL2-devel)
# Use the distro package manager or a preinstalled prefix.
#
# No-root / no package installation:
#   Put the development headers and libraries in a persistent local prefix
#   (do NOT use /tmp; it is cleared on reboot), then set:
#     PATH         -> prefix/bin        (for sdl2-config)
#     CPATH        -> prefix/include    (headers)
#     LIBRARY_PATH -> prefix/lib        (libraries)
#   The prefix path/name is arbitrary; the build does not depend on a specific
#   location. A self-contained prefix needs readline, ncurses/tinfo, zlib,
#   SDL2 and SQLite3 development files.


# =============================================================================
# 4. OS differences
# =============================================================================
# Ubuntu 22.04 (verified):
#   glibc 2.35; GCC 11.4; CMake 3.22; all required components are available
#   through the distribution or a local prefix.
#
# CentOS 7.9 userland / EDA container:
#   glibc 2.17. The default gcc/g++ 4.8.5 is not sufficient for the C++14
#   sources and the `-std=gnu++14` flag used by difftest; use devtoolset-8/9/11
#   or a newer GCC. The default CMake/Flex may be too old for DRAMsim3 and
#   Verilator 4.204; provide current versions. Verilator 4.204 is not in the
#   CentOS 7 base repositories; use a container-provided or built copy.
#
# EDA container:
#   Synopsys/Cadence/Mentor tools are preinstalled under /opt/eda and licensed
#   through /etc/profile.d/eda-env.sh. Their compiler (often gcc 4.8.5) is not
#   the build toolchain for this repository. Use a C++14-capable environment
#   for Verilator/difftest builds; EDA tools are used only for PPA evaluation.
#
# No install commands are given because package names and repositories differ.
