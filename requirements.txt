# =============================================================================
# 2. Verilator 4.204 (required)
# =============================================================================
# `verilator --version` must report:
#   Verilator 4.204 2021-06-12 rev v4.204
#
# Build from source:
#   git clone https://github.com/verilator/verilator.git
#   cd verilator
#   git checkout v4.204
#   autoconf
#   ./configure --prefix="$HOME/tools/verilator-4.204"
#   make -j"$(nproc)"
#   make install
#   export PATH="$HOME/tools/verilator-4.204/bin:$PATH"
#
# Do not rely on Ubuntu 22.04's default Verilator (4.038): this project was
# tested with 4.204 and the build scripts assume its command-line behavior.


# =============================================================================

# =============================================================================
# 4. No-root alternative for the C/C++ development files
# =============================================================================
# If you cannot install the -dev packages above (no sudo), extract them into a
# persistent directory. Do not use /tmp: it is cleared on reboot and the build
# will then fail with errors such as:
#   fatal error: SDL2/_real_SDL_config.h: No such file or directory
#   fatal error: zlib.h: No such file or directory
#
#   mkdir -p /tmp/debs "$HOME/tools/oscpu-dev-deps"
#   cd /tmp/debs
#   apt-get download libreadline-dev libtinfo-dev zlib1g-dev \
#     libsqlite3-dev libsdl2-dev
#   for f in *.deb; do dpkg-deb -x "$f" "$HOME/tools/oscpu-dev-deps"; done
#
# This self-contained tree supplies all headers, static libraries and the
# sdl2-config helper; no extra prefix (such as ~/tools/nemu-deps) is required.


# =============================================================================
# 5. Environment variables
# =============================================================================
# After the dependencies are in place, set (see README.md "使用流程"):
#
#   cd ~/oscpu-dyw
#   export NEMU_HOME="$PWD/libraries/NEMU"
#   export PATH="$HOME/tools/oscpu-dev-deps/usr/bin:$PATH"
#   export CPATH="$HOME/tools/oscpu-dev-deps/usr/include/x86_64-linux-gnu:$HOME/tools/oscpu-dev-deps/usr/include"
#   export LIBRARY_PATH="$HOME/tools/oscpu-dev-deps/usr/lib/x86_64-linux-gnu"
#
# When using system-installed -dev packages, the CPATH/LIBRARY_PATH lines can
# be omitted. NEMU_HOME is still required at emu runtime.
#
# The build scripts set NOOP_HOME and DRAMSIM3_HOME themselves; do not override
# them unless you know what you are doing.


# =============================================================================
# 6. Python packages
# =============================================================================

# =============================================================================
# 7. Compute / storage
# =============================================================================
# Tested on: 16 cores, ~15 GiB RAM, ~947 GiB free disk.

# A full emu build plus the three C++ dependencies fits comfortably in a few
# GiB; the bulk of the disk usage comes from the toolchains and git history.
# More cores/RAM mainly reduce the Verilator C++ compile time.
